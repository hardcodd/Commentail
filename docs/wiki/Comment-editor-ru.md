# Редактор комментариев (1.5.0)

[English](Comment-editor.md). Доступен начиная с Commentail 1.5.0.

В **Комментарии → Настройки сайта → Редактор комментариев** отдельно для гостей
и зарегистрированных выбирается простой текст, Markdown или визуальный редактор.
Для сайта доступны девять общих переключателей: жирный, курсив, зачёркивание,
ссылки, цитаты, маркированные и нумерованные списки, строковый и блочный код.
На уровне отдельных страниц эти настройки не переопределяются; в словарь
`COMMENTAIL` они не входят.

Миграция `0020` сохраняет простой текст как начальный режим обоих участников
и формат существующих комментариев/правок. Старые `**звёздочки**` остаются
буквальными и при редактировании. Для новых комментариев формат определяется
сервером по настройкам сайта; поле POST не позволяет его подменить.
Сервер проверяет все вложенные элементы разметки. Отключение формата не меняет
опубликованный текст. При правке старого Markdown после перехода сайта на простой
текст открывается исходник: запрещённое оформление потребуется убрать.

Прежний переключатель «Кликабельные ссылки» управляет автоматическим выделением
адресов в простом тексте. Явные Markdown-ссылки разрешает новый переключатель
«Ссылки».

Собственный обработчик поддерживает строковое оформление, явные ссылки
HTTP/HTTPS/mailto, цитаты, списки и код. HTML, entities, заголовки, таблицы,
изображения, подписи title и автоматические ссылки не входят в диалект.
Продолжения цитат и списков задаются явно. Примеры Markdown помещаются в код:
маркеры и пробелы внутри него сохраняются. Вложенная нумерация отображается
как `1.1`, `1.2`. Вставленный web-адрес получает короткую подпись доменом,
сохраняя полный адрес и значимые поддомены; страницы по ссылкам не запрашиваются.

Визуальный режим поддерживает зачёркивание, простые цитаты и списки. Вложенные
цитаты, сложные пункты и ссылки через перенос доступны в исходнике.
Неподдерживаемая команда отклоняется до изменения документа. Если последующая
правка текста создаст непредставимое сочетание стилей, команда «Снять оформление»
убирает строковые стили и ссылки выделения, сохраняя текст, структуру и код.
Перед экспортом на копии убираются краевые пробелы абзацев/пунктов и завершающие
пустые абзацы; код не подрезается.

При наборе преобразуются `**жирный**` / `__жирный__`, `*курсив*` / `_курсив_`,
`~~зачёркивание~~`, строковый код в обратных кавычках и `[текст](https://example.com)`.
В начале абзаца `- `, `* `, `+ `, `1. ` / `1) ` и `> ` включают список или цитату;
три обратные кавычки или тильды с Enter открывают блок кода. Одна отмена возвращает
буквальные маркеры. Они должны быть без оформления, вне кода и ссылок. Вставка,
IME и замена текста не запускают сокращения. Поиск ограничен 512 единицами UTF-16
и 64 возможными началами; для длинных фрагментов доступны панель и исходник.
Запрещённое или непредставимое преобразование оставляет текст буквальным.

Без JavaScript или при недоступном скрипте остаётся обычная textarea с теми же
серверными правилами. Ошибки сохраняют черновик; постоянного автосохранения нет.
Дополнительные JS/CSS и выбранный перевод загружаются только для визуального режима. Штатные теги
`commentail_css` / `commentail_js` остаются прежними; после обновления нужен
`collectstatic`. Заменённые шаблоны формы, правки и вывода нужно согласовать
с новым контрактом: оформленный текст выводится в блочном контейнере.

Лимиты парсера: 100 000 единиц UTF-16, глубина 32, 100 000 узлов и два миллиона
единиц работы. Ограничение длины сайта по-прежнему применяется к исходнику,
адрес ссылки ограничен 2048 символами. HTML экранируется; опасные схемы,
учётные данные и управляющие символы в адресах отклоняются.

Сообщения редактора доступны на английском, русском, немецком, французском,
испанском и бразильском португальском. Сервер выбирает активный язык Django:
загружается только его отдельный каталог; английскому он не нужен. Неизвестный
язык использует английский. При недоступном переводе или редакторе остаётся
обычная textarea.

Панель инструментов занимает один шаг Tab. Стрелки влево/вправо выбирают кнопку,
Home/End переходят к краям панели, Enter/Пробел применяют команду. Alt+Shift+T (Option+Shift+T на Mac) или Alt+F10 переводит
фокус из текста на панель, Escape возвращает к тексту. В списке Escape, затем Tab
выводят из редактора без изменения вложенности. Оба режима содержат переведённую
сворачиваемую подсказку. При ошибке отправки фокус возвращается к комментарию с доступным
описанием ошибки; исправление текста снимает признак ошибки. В окне ссылки
с клавиатуры доступны сохранение, удаление и отмена по Escape с возвратом выделения.

Сборка и проверки: [исходники редактора](../../frontend/editor/README.md).
См. также [настройки](Configuration.md) и [контракт шаблонов](Template-contract.md).

Ответ на собственный комментарий запрещён: для аккаунтов проверяется ID автора,
для гостей — нормализованный email. Старые ответы себе остаются видимыми.
