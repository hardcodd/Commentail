# Документация Commentail

[English](Home.md) · Русский

**Комментарии для Wagtail CMS на вашем сервере.** Подключите обсуждения с модерацией
к страницам Wagtail и зарегистрированным Django-моделям, используя учётные записи,
шаблоны и оформление своего сайта.

> **1.4.1 Stable:** Wagtail 7.4.3+ с Django 5.2 или 6.0; Wagtail 8.0 с Django 5.2,
> 6.0 или 6.1; Python 3.12–3.14; файловая SQLite и PostgreSQL 16.
> Для опубликованной 0.1.0 сохраняется поддержка Wagtail >=7.4.3,<7.5 и Django 5.2.

Гостевые комментарии защищены скрытыми проверками формы, лимитами попыток и
сигналами повторяющегося текста и большого числа ссылок. Google reCAPTCHA v2 и
Яндекс SmartCaptcha подключаются по желанию; по умолчанию используется
арифметическая проверка. Настройте отправку писем Django и одно расписание фоновой
обработки — командой или через очередь задач проекта.

Версия 1.4.0 добавляет
[отдельную настройку почты и команду проверочного письма](Email-configuration-ru.md),
а также ранний отказ гостю по жёстким правилам с причинами и поддержкой CSV.
Патч 1.4.1 исправляет описание PyPI без изменения кода.
См. [текущий выпуск](Release-1.4.1-ru.md) и [обновление с прежних версий](Release-1.4.0-ru.md).
При переходе с 1.3.0 и более ранних версий также нужна
[процедура необратимой миграции 1.3.1](Release-1.3.1.md).

## Первый запуск

1. Пройдите установку на тестовом сайте.
2. Начните с политики **Review all**: по умолчанию все комментарии проверяются.
3. Настройте [отправку писем и её расписание](Email-and-worker.md), прежде чем
   включать гостей. Выберите рабочий почтовый backend и одно расписание.
4. Проверьте публикацию, ответ и разрешённое редактирование.
5. Настройте оформление и права модераторов в пределах сайта.

Обычный текст, серверная разметка и необязательный JavaScript позволяют подключить
виджет без фронтенд-фреймворка. Интерфейс, модерация и письма доступны на английском,
русском, немецком, французском, испанском и бразильском португальском;
см. [настройку языков](Configuration.md#languages).
Внешняя платформа комментариев, Redis, Celery и CDN не обязательны.
