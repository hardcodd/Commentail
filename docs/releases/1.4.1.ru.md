# Commentail 1.4.1 — исправление описания пакета

[English](1.4.1.md) · Русский

**Стабильный выпуск · 26 октября 2026 · MIT.**

Этот патч документации публикует на PyPI исправленный README и актуальные
команды установки. В загруженной 1.4.0 остались пометки кандидата и команды
для 1.3.2. Версия пакета и исполняемый код были правильными; прежние архивы
не заменялись.

Исполняемые файлы, зависимости и миграции совпадают с 1.4.0. Для установленной
1.4.0 дополнительные миграции или изменения настроек не нужны.

Для новой установки используйте `python -m pip install commentail==1.4.1`.
При обновлении с 1.3.2 или раньше следуйте
[инструкции обновления 1.4.0](1.4.0.ru.md), устанавливая 1.4.1 на первом шаге.
Требования миграции `0019` и более ранней необратимой `0018` сохраняются
там, где они применимы. Перед изменением рабочего сайта сделайте резервную
копию и отрепетируйте обновление.

Матрица совместимости, независимая почта, команда проверочного письма и ранний
отказ по правилам не изменились. См.
[руководство по настройке почты](../wiki/Email-configuration-ru.md).
