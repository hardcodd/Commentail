# Commentail 0.1.1

**Beta · 19 October 2026 · MIT**

This update expands framework compatibility and fixes guest-name and mail-link
behavior. Install with `python -m pip install commentail==0.1.1`.
See the [0.1.0 → 0.1.1 comparison](https://github.com/hardcodd/Commentail/compare/v0.1.0...v0.1.1)
and the [version history](../../CHANGELOG.md).

## Changes since 0.1.0

- Support Wagtail 7.4.3+ within 7.4 with Django 5.2 or 6.0, and Wagtail 8.0.x
  with Django 5.2, 6.0 or 6.1, on Python 3.12–3.14.
- Generate email action and status links using the configured Commentail URL
  prefix, including nested paths.
- Limit new guest names to 40 Unicode graphemes after trimming, with server
  validation and progressive browser feedback. Preserve existing names and
  registered-account names.
- Give the guest-name label a translation context so host-site translations for
  other uses of "Name" do not replace the author label.
- Extend regression coverage for capability access, extension and presentation
  contracts, transactions, concurrency and worker recovery.

## Compatibility

The supported database matrix is file SQLite and PostgreSQL 16. Each of the five
framework pairs above is exercised on Python 3.12, 3.13 and 3.14 with both databases
(30 combinations). Wagtail 7.4 with Django 6.1 and Wagtail 8.1+ are outside scope.
Keep Beta expectations: this is not a stable 1.0 release.

## Upgrade from 0.1.0

1. Back up the database, media, settings, secrets and exact package/dependency
   versions; rehearse restoration and keep rehearsal mail local.
2. In the test environment, run `python -m pip install --upgrade commentail==0.1.1`.
   If using a downloaded wheel, verify its checksum before installation.
3. With PostgreSQL, include `django.contrib.postgres` in `INSTALLED_APPS`, as
   required by Django 6.x checks. Keep the framework pair within this matrix.
4. Run `migrate`, `check` and `collectstatic`. No new Commentail migrations are
   included; a framework upgrade can still have its own migrations.
5. Review overridden guest forms for the 40-grapheme guidance and validation
   attributes. Existing stored names are not truncated or rewritten.
6. Test guest confirmation, moderation, replies, edits and queued mail at your
   actual URL prefix before restoring normal traffic and the worker.

Python hooks and URL names are unchanged. Already queued mail uses the installed
version's URL generation when sent; previously delivered links are not rewritten.
SMTP uncertainty can still cause duplicate delivery. Public API, browser and
accessibility guarantees are not expanded by this update.
