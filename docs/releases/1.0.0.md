# Commentail 1.0.0

**19 October 2026 · Stable · MIT**

The feature set is frozen at published 0.2.0 Beta. This release starts the
[stable API and compatibility policy](../wiki/Stability.md); it introduces no
runtime changes, new dependencies or database migrations beyond 0.2.0.
Install from [PyPI](https://pypi.org/project/commentail/1.0.0/); archives and checksums
are available in the [GitHub release](https://github.com/hardcodd/Commentail/releases/tag/v1.0.0).

## Included

Self-hosted Page/object discussions; Site/Page settings; site accounts and
email-verified guests; four moderation policies; threaded replies and moderated
author edits; protected links and per-comment unsubscribe; database mail queue;
custom templates, callbacks, CAPTCHA and object adapters; structured data;
recent-comment selection with host markup; six UI/email languages; HTML/plain-text
emails; and indexed database reads. See the [0.2.0 notes](0.2.0.md) for its additions.
Most-discussed threads remain deferred.

## Upgrade

Back up the database, media, host settings/templates, `SECRET_KEY` and exact
versions. Rehearse with `python -m pip install --upgrade commentail==1.0.0`
in a restored test environment. Keep rehearsal mail local.

- From 0.2.0: no Commentail schema migration is added. Run normal `migrate`,
  `check` and `collectstatic --noinput`; verify existing host overrides and queues.
- From 0.1.0 or 0.1.1: also follow the [0.1.1](0.1.1.md) and
  [0.2.0](0.2.0.md) upgrade notes. Migration `0014_reading_indexes` builds indexes
  and SQLite remakes the rate-event table. Measure migration cost on representative
  data and plan a maintenance window where needed.
- Restore pre-upgrade and post-upgrade backups independently. Verify old tokens,
  pending revisions, permissions, settings, subscriptions and queued mail; then
  exercise new writes and local delivery. A wheel downgrade alone is not recovery.

## Verification

Candidate verification and acceptance on an integrating site are separate. Check
the host theme, access rules, email delivery and scheduled worker on that site.
An owner-supplied report dated 19 October 2026 covers published 0.2.0 on a live
integrating site: guest confirmation/editing/moderation, Gmail/Yandex delivery,
reply notifications, unsubscribe, upgrade/restoration and 24 negative token/CSRF
cases. [Verification scope and observations](../wiki/Example-and-testing.md#reported-live-site-verification-020)
include initial Yandex spam placement and the ordinary form shown on repeated
confirmation. These results support the unchanged 1.0.0 runtime; they
are not a live-site test of an installed 1.0.0 package.
The installed 1.0.0 candidate passed 314 server tests on each of two framework
pairs with SQLite and PostgreSQL 16, 33 JavaScript tests, package checks and
independent upgrade/restoration rehearsals. Historical-browser checks covered
Chrome 142 and Firefox 140 ESR with and without JavaScript; Windows checks used
ARM64, with Chrome x64 under emulation. Native Windows x64 was not tested.

Support, compatibility promises and verification limits are defined by
[Stability](../wiki/Stability.md). No exhaustive browser/device/WCAG certification,
native-language review or universal server-capacity guarantee is claimed.
